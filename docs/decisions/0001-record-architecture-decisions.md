# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-27

## Context

Architectural reasoning is lost if it lives only in code, commits, or chat history.

## Decision

Record architectural decisions as ADRs in `docs/decisions/`. When an ADR is required, its format, and its lifecycle are defined in [README.md](README.md).

## Consequences

- The rationale behind the design stays traceable.
